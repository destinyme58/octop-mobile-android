# Changelog

All notable changes to Octop Mobile are documented in this file.

## [1.0.1] - 2026-10-25

### Added

- Android WebView client for self-hosted Octop instances.
- Bottom navigation for chat, experts, tasks and more.
- Configurable HTTP/HTTPS server address.
- Pull-to-refresh, offline handling and in-app retry state.
- File upload/download, camera, microphone and SSO popup support.
- Session persistence and a one-action login/cache reset.
- Build-time APK versioning with platform, ABI, version and date metadata.
- GitHub Actions verification and APK artifact builds.

### Fixed

- Android system back navigation now follows the WebView history.
- Status and navigation bars respect system insets and light/dark mode.

## [1.0.0] - 2026-10-25

- Initial internal preview build.
