首个公开版本，提供面向自托管 Octop 的 Android 移动端入口。

## 主要功能

- 原生 Android 外壳承载 Octop 官方 Web 应用，兼容服务端登录、验证码和 SSO。
- 底部导航支持对话、专家、任务和更多功能。
- 支持任意局域网 HTTP/HTTPS Octop 服务地址。
- 下拉刷新、离线提示、重试和系统返回键导航。
- 文件上传/下载、摄像头/麦克风和授权弹窗支持。
- 登录会话持久化，以及一键清除登录状态和缓存。

## 安装包

- 文件：`Octop-Mobile_Android_universal_v1.0.1_20261025_debug.apk`
- 平台：Android 8.0（API 26）及以上
- 架构：Universal，适用于当前所有 Android CPU 架构
- 版本：versionCode 2 / versionName 1.0.1
- SHA-256：`39115ce7bd0aaa330ecaadf48241546426fb0061e68c8575039bd9afb5896523`

首次打开后，在“服务器设置”中填写自己的 Octop 地址。该版本使用 Android debug
签名，适合个人测试和内部使用；正式发布前应改用独立的 release keystore。

## 说明

本项目是非官方客户端，与腾讯云及 Octop 官方无隶属关系。登录凭据和业务数据由用户
配置的 Octop 服务器处理，客户端源码与安装包均不内置登录密码。
