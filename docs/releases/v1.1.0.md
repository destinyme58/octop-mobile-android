# Octop Mobile v1.1.0

这是基于 [huangcheng/OctopMobile](https://github.com/huangcheng/OctopMobile)
`v1.0.0`（源码提交 `524f3564ff192c86c73778d33ea58b4de87b0e8e`）构建的非官方
Android Release。界面、设计与原始实现由 [@huangcheng](https://github.com/huangcheng)
完成；感谢作者公开这套完整的移动客户端。本项目与原作者、腾讯云和 Octop 官方均无
隶属或背书关系。

## 安装包

- 文件：`Octop-Mobile_Android_universal_v1.1.0_20261025_release.apk`
- 包名：`com.destinyme.octopmobile`
- 版本：versionCode 3 / versionName 1.1.0
- 系统：Android 7.0（API 24）及以上
- 架构：Universal（`arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64`）
- SHA-256：`03cb5c2500b27f3de4bff296c33053bef6029ca8cb76bcb67848432366e5cb8e`
- 签名证书 SHA-256：`7ffc2804da222b6dafdf1091e0b80b865096fdf8660ceac16b13f80301780353`

Release 资产同时提供同名 `.sha256` 文件。APK 使用独立 release keystore 签名，
后续同包名更新必须继续使用同一证书，否则 Android 会拒绝覆盖安装。

## 本版改动

- 增加原生 Expo 配置插件，确保 Release Manifest 启用局域网明文 HTTP。
- 保留原作者的一次性 HTTP 风险确认框；HTTPS 证书校验不会被绕过。
- 使用独立包名、版本号和签名，可与作者原版同时安装。
- 修复登录返回 HTTP 401 时页面重新挂载、用户名和密码被清空的问题。
- 移除上游 EAS owner/project 绑定，源码可在本地直接 prebuild 和构建。
- 补充来源、修改记录、构建说明和许可证差异说明。

## 验证

- TypeScript 类型检查通过。
- 17 个 Jest 测试套件、81 个测试全部通过。
- Android Release 的 arm64-v8a、armeabi-v7a、x86、x86_64 原生模块编译通过。
- APK v2/v3 签名验证通过；Manifest 包含
  `android:usesCleartextTraffic="true"`、versionCode 3 和 versionName 1.1.0。
- 在 Android API 36 模拟器中冷启动、HTTP 风险提示和认证失败表单保留流程通过。

## 安全提示

明文 HTTP 不会加密密码、Token 或聊天内容。除完全可信的私有网络外，应给 Octop
配置有效 HTTPS 证书。该构建不会关闭 TLS 校验，也不会把登录密码写入 APK 或源码。
